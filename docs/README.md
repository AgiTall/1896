# Разработка «Песни Земли»

Рабочая точка входа. Основной старт — 1 января 1893 года (подтверждено автором). Основная кампания — 1893–1897 включительно; продолжение — 1898–1902.

- [Авторский канон](WORLD_CANON.md) — сохранён без редакторских изменений.
- [План разработки](DEVELOPMENT_PLAN.md) — этапы, страны, зависимости и критерии готовности.
- [Первый сюжетный блок](FIRST_CAMPAIGN.md) — проектирование конфликта Батавии и Японии.
- [Вопросы и расхождения](CANON_QUESTIONS.md) — что нужно определить до изменения сюжета и карты.

Канон описывает мир. План и проект первого блока содержат предложения реализации, а не новые утверждённые факты мира. Автор подтвердил альтернативные пути с направляющим таймером войны. Последние уточнения имеют приоритет над исходным каноном: см. AUTHOR_DECISIONS.md.

Новые отдельные кампании: [Британский Левиафан](BRITISH_CAMPAIGN.md) — 96 фокусов, [связка с 21 эпизодом хроники](BRITISH_STORY_LINKS.md), политические пути, морская империя и научные проекты; [Австралия](AUSTRALIAN_CAMPAIGN.md) — шесть деревьев и договорная федерация.

## Изменения этой ревизии

Дата единственного bookmark перенесена с 1877 на 1893, добавлены отдельные RU/EN название и описание сценария. Стартовая история, карты, технологии, персонажи, фокусы и таймеры сохранены. Перенос даты сам по себе не означает готовность мира 1893 года. Имена OOB A01_1877 и A03_1877 пока оставлены как действующие технические ссылки.

Для проверки старта нужна новая кампания. Ответы Q01–Q05 получены. Следующая работа: послевоенная Индонезия, параметры ТНП и аудит карты; остаточные вопросы находятся в CANON_QUESTIONS.md.

## Правила работы

1. Сначала закончить первый связный сюжетный блок, затем расширять страны и годы.
2. Изменение канона записывать отдельно от технической реализации.
3. Каждая сюжетная задача должна иметь условия запуска, отмены, повторного выполнения и последствия для других участников.
4. Завершение задачи: статическая проверка плюс игровой прогон, если меняется поведение кампании. Если прогона нет, явно записать ограничение.
5. Генераторы tools/build_* и старые миграционные скрипты не запускать вслепую: часть использует снимки и перезаписывает ручные правки.
6. Git сейчас обнаруживается выше папки мода и охватывает посторонние пользовательские проекты. До коммитов организовать отдельный репозиторий мода; не добавлять файлы из родительского репозитория целиком.
