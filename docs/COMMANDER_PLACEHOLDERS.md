# Заготовки командиров

Для A01 (Ост-Индия), A02 (Британия), A03 (Япония), A04 (ВТП), A06 (Россия в изгнании) и A07 (Австралия) добавлено по пять генералов и одному фельдмаршалу. Всего 36 новых персонажей, доступных с начала новой кампании. Существующие персонажи сохранены.

Все заготовки имеют первый уровень, четыре навыка по 1 и пустой список черт. Номер и тег страны позволяют различать их до переименования. Портреты — силуэты, у каждого персонажа собственный файл.

- Имена: `localisation/russian/major_commanders_l_russian.yml`; английские имена — в одноимённом файле английской локализации.
- Параметры персонажей: `common/characters/A01_commander_placeholders.txt` и аналогичные файлы других пяти стран.
- Портреты: `gfx/leaders/A01/placeholders/` и аналогичные папки других стран. `marshal_01.dds` — фельдмаршал, `general_01.dds`–`general_05.dds` — генералы. Можно заменить файл портрета, сохранив имя и формат DDS.

Например, имя первого генерала Ост-Индии задаёт ключ `A01_placeholder_general_01_name`, портрет — `gfx/leaders/A01/placeholders/general_01.dds`. Его характеристики и черты находятся в блоке `A01_placeholder_general_01`.

Одноразовый генератор `tools/create_major_commanders.py` отказывается перезаписывать существующие файлы персонажей, чтобы сохранить последующие ручные изменения.
