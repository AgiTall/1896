# Проверка повторной ошибки загрузки

Исправления сценариев подтверждены: в новых запусках нет Error:, Unknown trigger, parser.cpp и ошибок удаления динамических модификаторов.

Проверены отдельно:

1. 1896 + исходный Modifier Icons: Failed allocate data buffer при подготовке сценария.
2. Только 1896, с пересозданным кэшем морских расстояний: та же запись.
3. Чистая игра без любых модов, сценарий 1936: та же запись gamelobby.cpp:1779 / remotefile.cpp:238. Лог — tools/vanilla_control_load_errors.log.

Пустой legacy positions.txt не был причиной: заполнение комментариями не изменило результат. Исходное пустое содержимое восстановлено. Проверка размещения зданий и портов прошла.

Исправлен синтаксис пути старого неактивного 18xx.mod: обратные слеши заменены прямыми, целевой каталог сохранён. Исходник — tools/18xx_descriptor_before_load_repair.mod. Это убрало семь lexer-ошибок при сканировании установленных модов.

Дата NDefines.NGame.START_DATE приведена к единственной закладке 1893.1.1.12; это не устранило исключение буфера.

После тестов исходный список включённых модов и оригинальные файлы кэша восстановлены. Тестовые процессы завершены. Свободно около 8.7 ГБ ОЗУ, 134 ГБ на C и 470 ГБ на D: явного исчерпания памяти/места не обнаружено.

Успешный вход в кампанию не подтверждён. Исключение воспроизводится и вне мода; следующая проверка должна охватить целостность установки игры и чистый пользовательский профиль. Саму запись исключения нельзя считать доказательством единственной причины видимого окна без проверки в интерфейсе.
