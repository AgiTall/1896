# Проверка запуска 19 октября 2026

Воспроизведено завершение запуска после выбора A01 с системным окном «Не удалось загрузить карту». Текст системного окна отображался как UTF-8, ошибочно прочитанный в однобайтовой кодировке.

Диагностический журнал указал четыре ошибки statehistory.cpp:306. Начальные укрепления превышали ограничения местности перенесённой системы TGWR. Исправлены только указанные записи: bunker в провинции 6529 с 10 до 3; coastal_bunker в провинциях 383, 3151 и 2489 с 5 до 4. Исходные файлы сохранены в tools/backups/crash_fix_20261019/history/states.

Также восстановлена регистрация семи тегов специальных проектов для совместимости с базовыми модификаторами учёных и идей. Это не добавляет проекты в заменённый набор мода.

После исправлений в запуске 10:06–10:07 с 1896, FPS Map и Modifier Icons четыре ошибки укреплений отсутствуют. Через computer-use визуально подтверждён вход в кампанию A01: игровой интерфейс и дерево фокусов, дата 1 января 1893 года. Дальнейшая симуляция и длительная стабильность не проверялись. В журнале остаются многочисленные ошибки совместимости базового контента; вход в кампанию не означает их устранения.

Журнал проверки сохранён в tools/map_after_fort_fix_20261019_errors.log. Запись Failed allocate data buffer остаётся и не помешала этому входу в кампанию.
