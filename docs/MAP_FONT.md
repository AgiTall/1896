# Названия стран на карте: Miranda Script

Шрифт пользователя скопирован в gfx/fonts/mirandascript.ttf. Поддерживает весь русский алфавит, включая Ё/ё. Скрипт tools/build_map_font.py создаёт игровой bitmap-атлас gfx/fonts/hoi_mapfont4.dds и метрики gfx/fonts/hoi_mapfont4.fnt. Размер атласа 2048×1024, четыре mip-уровня; высота строки 84 и базовая линия 70 согласованы со штатными метриками.

Используется слот карты tahoma_60: основной файл подменяет карту с латинскими названиями, а interface/zzz_1896_map_font.gfx явно задаёт тот же атлас для русского языка. Интерфейсные шрифты меню не менялись. Для редких отсутствующих символов в атласе сохранён резервный Tahoma. Соединения и лигатуры ограничены возможностями bitmap-рендерера HOI4; кернинг между буквами записан в FNT.

Проверка и предпросмотр из фактического игрового атласа: tools/validate_map_font.py; результат — tools/miranda_map_font_preview.png. Проверены границы глифов, русский алфавит и DDS. Требуется перезапуск игры; новая кампания не нужна. Вид и размещение подписей в движке ещё не проверены.

Прежние шрифт, настройки и генератор сохранены в tools/backups/map_font_before_miranda. Для отката вернуть оттуда файлы по исходным путям.

Исправление по журналу игры: атлас 2048×2048 вызывал Failed to load texture larger than MAX_TEXTURE_SIZE, из-за чего исчезали подписи. Атлас пересобран в штатном размере 2048×1024; все 575 символов поместились без уменьшения рисунка букв.
