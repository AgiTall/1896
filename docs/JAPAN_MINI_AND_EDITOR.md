# Япония и редактор стран

Новая ветка A03: три промышленных фокуса (140, 140, 105 дней), затем четыре сюжетных по 35 дней. Награды: три гражданские фабрики в регионе 282, три военных завода в 531, две верфи в 528; выдаются дополнительные ячейки. Регион должен принадлежать Японии.

Дипломатические фокусы открывают предложения протектората A08, A10, A01. Цена — 100 политической власти, длительность — 30 дней. Обе страны должны быть в мире, адресат — независимым. Согласие создаёт марионетку; отказ даёт цель войны на подчинение. Веса ИИ: 60/40. Каждый договор предлагается один раз.

После первого промышленного фокуса доступна [морская программа](JAPAN_MARITIME_PROGRAMME.md): шесть решений, пять событий и два взаимоисключающих приоритета флота. Ремонтные контракты и угольные склады открываются по мере завершения мастерских и верфей. Программа проверяется отдельно командой `py tools/validate_jmc_maritime.py` и входит в общий набор текущего содержимого.

Старая ветка, японские on_actions, категории решений и план ИИ сохранены с исходными путями в tools/backups/japan_before_mini_20261019. Для восстановления скопируйте снимок обратно и удалите новые JSM_story в common/decisions, common/decisions/categories и events. Старые эффекты, идеи и события оставлены для внешних ссылок. Фоновые японские on_actions отключены; старые категории JP скрыты за невыставляемым флагом JSM_legacy_campaign_enabled. Сюжеты других стран сохраняются.

Запуск редактора — country_editor.bat в корне мода. Используется Python среды Codex или системный Python 3 с tkinter и Pillow. На другом компьютере: pip install -r country_editor_requirements.txt.

Рядом с загрузкой флага, портрета правителя и добавлением генерала есть кнопка «Вставить из буфера». Поддерживаются скопированное изображение, снимок экрана и файл изображения, скопированный в Проводнике. Выберите страну, а для генерала также заполните имя и черты, затем нажмите соответствующую кнопку. Размеры подгоняются автоматически; флаг сохраняется в трёх версиях. Если в буфере только текст или нет изображения, появится сообщение без изменения файлов.

Страна находится по тегу или русскому названию. Три квадрата показывают текущие размеры флага, четвёртый — портрет выбранного правителя. Отсутствующие изображения оставляют пустой квадрат. Для флага учитывается начальная правящая идеология; для портрета читаются прямые пути и ссылки GFX из interface. Предпросмотр обновляется после загрузки.

Большой PNG флага автоматически масштабируется целиком в TGA 82×52, 41×26, 10×7, включая существующие идеологические варианты. Края флага не обрезаются. Портрет правителя выбирается из персонажей страны и сохраняется в DDS 156×210 и 65×67 (если малый портрет прописан). Портреты обрезаются по центру.

Добавление генерала создаёт персонажа с уникальным ID, именем, портретом DDS, выбранными чертами и начальными навыками 1, прописывает recruit_character и локализацию двух языков. Если локальных черт нет, показывается базовый список; дополнительные ID вводятся вручную. Их наличие нужно сверять с используемой версией игры. Страны с правителями вне common/characters требуют ручной правки.

Копии перед заменой — tools/backups/country_editor с отметкой времени. Требуется новая игра. Проверка редактора в отдельной временной папке: tools/test_country_editor.py. Проверка в HOI4 не выполнена.
