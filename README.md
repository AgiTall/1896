# 1896

Мод альтернативной истории для **Hearts of Iron IV**. Начало кампании — 1896 год.

Версия мода: **0.1**. Версия игры, указанная в `descriptor.mod`: **1.19.2.0**.

## Установка

1. Скачайте репозиторий и поместите его содержимое в папку `Documents/Paradox Interactive/Hearts of Iron IV/mod/1896`.
2. В соседней папке `mod` создайте файл `1896.mod`: скопируйте в него содержимое `1896/descriptor.mod` и добавьте строку `path="mod/1896"`.
3. Добавьте мод в набор модов в Paradox Launcher и включите его.

Мод заменяет историю стран, регионов и войск, поэтому совместимость с другими крупными модами не гарантируется.

## Содержимое

Игровые файлы находятся в `common`, `events`, `history`, `map`, `localisation`, `gfx` и `interface`. Документация разработки — в `docs`, инструменты и проверки — в `tools`.

Монархическая ветка Нидерландов включает борьбу с советом адмиралов, реформы королевских институтов, отношения с султанатами и индонезийцами, конституционную монархию и выборы премьер-министра.

Проект находится в разработке. Локальные ключи редактора, резервные копии и журналы игры не включены в репозиторий.
